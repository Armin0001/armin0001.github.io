Role fit TypeScript · Node.js · PostgreSQL

Full-Stack Engineer.

I lean frontend, but I do not stop at the API boundary. I have designed the schema, written the access rules, wired up the storage and run the deploys, on my own, for a system people depend on.

Why I fit

  1. I have owned a whole system, not a slice of one

    As a freelance developer I was the only engineer on a production membership registry for a professional licensing body. I gathered the requirements from a non-technical client, designed the PostgreSQL schema, built authentication and session handling, integrated object storage and SMS, deployed it, and maintained it in production for around 40 member facilities. artifact A-01

  2. I start from the data model

    In that system the schema follows the real hierarchy: a legal entity, the licensed individuals registered under it, and each individual’s dues, fees and records. Access control is data too. Ten resources, four actions, forty permission combinations that admins change in a settings screen, with no redeploy.

  3. I take correctness under concurrency seriously

    Online Ticket Booth exists because of one question: what happens when two people buy the same seat in the same instant? The answer is an atomic, all-or-nothing claim in a Lua script on Redis, held to the same test contract as the in-process store and verified against real servers. artifact A-04

  4. I have worked both sides of the API at work

    At Artco Group I designed REST API workflows and authentication guards with role-based access control, and built full-stack features on Node.js and Firestore for admin modules and real-time dashboards. Before that I was a Node.js developer at WellBeing, helping maintain five high-traffic websites.

  5. One language, end to end

    TypeScript from the validation schema to the component means fewer seams for bugs to hide in. I have also run a product of my own on that stack since 2025: 15+ calculators on their own domain, built to be found by search. artifact A-03

Where I am most useful

I am a frontend-leaning full-stack engineer. The backend work I have done is Node.js, PostgreSQL and the services around them, at the scale a small team runs. That is the kind of full-stack role where I add the most: owning a feature from the table to the pixel, without a handoff in the middle.

What I am looking for

A product team where full-stack means exactly that, and where the person who designs the schema is trusted to ship the screen that uses it.

I am based in Zenica, Bosnia and Herzegovina, open to remote work, and available now.
